# Guía Coránica Integral

Una aplicación web interactiva diseñada para enseñar los fundamentos de la lectura del Corán, basada en una guía completa. Cubre desde el alfabeto árabe hasta reglas avanzadas de Tajweed.

## Desarrollo

Este proyecto fue creado con Vite, React, TypeScript y Tailwind CSS.

### Requisitos

- Node.js (versión 18 o superior)
- npm, yarn, o pnpm

### Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/your-username/guia-coranica-integral.git
   cd guia-coranica-integral
   ```

2. Instala las dependencias:
   ```bash
   npm install
   ```

### Ejecutar la aplicación

Para iniciar el servidor de desarrollo local:
```bash
npm run dev
```
Abre [http://localhost:5173](http://localhost:5173) (o el puerto que indique la terminal) en tu navegador.

### Compilar para Producción

Para crear una versión optimizada de la aplicación para producción:
```bash
npm run build
```
Los archivos estáticos se generarán en la carpeta `dist/`. Puedes desplegar el contenido de esta carpeta en cualquier servicio de hosting estático como GitHub Pages, Vercel, o Netlify.

### Vista Previa de la Compilación

Para previsualizar la versión de producción localmente:
```bash
npm run preview
```
